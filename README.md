# Pageleaf · 叶笺

把值得留下的网页，变成自己的 Markdown 笔记。

Pageleaf 是一个在本机运行的 Chrome 扩展。点击扩展图标，提取当前网页正文或选中文字，在独立阅读器中阅读、添加笔记，再保存到本机或导出 Markdown。无需账号、API Key 或付费服务。

[English](README.en.md) · [隐私说明](PRIVACY.md) · [贡献指南](CONTRIBUTING.md)

![Pageleaf 阅读器网页预览](docs/reader.png)

## 可以做什么

- **正文提取**：去掉文章周围的导航和杂项；选中文字时，只提取选中内容。
- **专注阅读**：文章目录、字体大小、浅色与深色主题。
- **可携带的笔记**：保留标题、链接、代码、列表和简单表格；附上来源与个人笔记，复制或下载 `.md` 文件。
- **本机笔记库**：明确点击保存后持久保存，可搜索、打开和删除。
- **按需读取**：只在你点击扩展图标或快捷键时读取当前页，没有常驻网页脚本和浏览历史扫描。

## 安装开发版

需要 Node.js 22 或更新版本及桌面版 Chrome。

```sh
npm ci
npm run check
```

打开 `chrome://extensions`，开启「开发者模式」，点击「加载已解压的扩展程序」，选择项目中的 **`dist` 文件夹**。在 Chrome 扩展菜单中固定 Pageleaf，打开一篇正常的 HTTP/HTTPS 文章后，点击它的图标。

若收到安装 ZIP，先解压，再选择解压后包含 `manifest.json` 的文件夹。不要选择源码根目录或 ZIP 文件。

## 使用

1. 打开一篇文章；如只需要某一段，可先选中文字。
2. 点击 Pageleaf 图标，在新标签页阅读提取结果。
3. 添加个人笔记，选择复制 Markdown、下载文件，或保存到本机笔记库。
4. 从阅读器打开笔记库，搜索或重新打开已保存的内容。删除前会再次确认。

复制和导出只作用于当前阅读器中的内容。链接查询参数、URL 中的用户名/密码及片段会被移除；如果原文依靠查询参数定位文章，导出的来源链接可能需要手工补充。

## 数据与权限

扩展需要 `activeTab`（点击时临时读取当前网页）、`scripting`（按需提取）、`storage`（保存笔记和偏好），没有站点常驻权限，不读取所有标签或浏览历史。

尚未保存的提取结果暂存在浏览器会话内存中，浏览器退出时清空。最多保留 6 份，新提取时清理超过 24 小时的临时内容。只有你明确保存的文章和笔记会写入本机 Chrome 配置目录，最多 100 篇，**未额外加密**。主题等阅读偏好也保存在本机。没有云同步、分析统计、广告或服务器；阅读器移除远程图片，避免加载图片时向原站发送请求。主动打开原文或文中链接，会由浏览器访问对应网站。

本机保存不等于适合保存秘密：请自行判断是否提取包含私人通信、身份、医疗或财务信息的页面。完整说明见 [PRIVACY.md](PRIVACY.md)。

## 开发与验证

```sh
npm test         # 提取、内容安全及其他自动化用例
npm run build    # 构建 dist；浏览器运行时不依赖 node_modules
npm run check    # 测试、构建、权限/资源/CSP 静态检查
npm run package  # 在项目上级目录生成安装包和源码包
```

依赖版本由 `package-lock.json` 固定。运行时代码随扩展打包，不从远程加载。构建工具和测试环境也有第三方依赖，许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

具体已完成与未完成的检查见 [验收记录](docs/VALIDATION.md)。自动化测试通过不代表 Chrome 实机验收完成。浏览器加载、图标触发、真实文章提取、复制/下载、刷新、保存后重开、删除与受限页面提示，应在发布前逐项验证。

## 当前边界

这是 **0.1.0 首个开发版本**，尚未在 Chrome 网上应用店发布。没有声明用户数、下载量、Stars 或长期维护记录。

提取效果取决于网页结构。PDF、图片文章、视频、复杂网页应用、浏览器内部页、Chrome 网上应用店等受限页面不支持；不绕过登录、付费墙或访问限制。只读取当前已经加载的内容，不下载尚未显示的分页或 iframe 内容。正文图片会被移除；复杂表格和数学公式可能需要手工调整。单篇提取有大小上限，达到上限时会给出提示。

## 本地界面预览

完成构建后，可从项目根目录运行 `python3 -m http.server 8765 --bind 127.0.0.1`，打开 `http://127.0.0.1:8765/dist/reader.html?demo`。网页预览只展示阅读器；保存仅在当前页面有效，刷新后清空，不是扩展安装与真实网页采集验收。
